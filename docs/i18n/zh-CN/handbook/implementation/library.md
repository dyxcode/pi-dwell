# 浏览 Current 内容库

[English](../../../../handbook/implementation/library.md) | 简体中文

[实现文档索引](README.md)

<a id="behavior"></a>

## 行为

Web 客户端通过一个对话框浏览可选的本地 Current 内容库。最新内容和搜索结果先展示有限长度的摘要；选中某条结果后，阅读器打开指定的准确版本。没有选中会话也可以浏览；只有选中 Dwell 会话后才能添加或移除引用。

附加到会话的引用包含 内容库绑定、条目身份和准确版本。添加引用会为所选会话保存这些身份，Pi 上下文保持不变。内容仍由 Current 持有。Current 不可用时，Host 仍可显示并移除已保存的引用；浏览内容、打开准确版本和添加新引用则必须连接到可用的内容库。

<a id="ownership"></a>

## 数据归属

Current 拥有采集到的正文、元数据和版本历史。Dwell 通过 Current 本地的版本化内容库接口 打开内容库，并提供只读且有长度上限的视图。Dwell Catalog 为会话保存稳定引用，以及绑定到规范化本地根目录的对应关系；Current 继续保留文章正文。

绑定是已配置内容库的本地身份。Catalog 会将一个绑定固定关联到最初的规范化根目录，尝试用同一绑定打开另一个存储库时会被拒绝。每个存储库使用独立绑定。没有配置 Current 时 Dwell 会照常运行；配置的 Current 模块无法打开时，会话 Host 仍可使用，但内容库读取不可用。

<a id="execution"></a>

## 执行顺序

1. 打开对话框后，客户端读取 Current 最新内容；如果已选中会话，也同时读取该会话已保存的引用。搜索会用匹配结果替换当前结果列表。
2. 选中一项后，客户端读取该条目的指定版本。阅读器显示标题、来源、采集日期、摘要、正文，以及来源完整度或截断信息。
3. 添加引用前，Host 要求已打开的 Current 内容库确认准确的绑定、条目和版本。重复添加同一引用不会产生重复记录。移除操作只删除这一条精确身份对应的引用。
4. 引用更新完成后，对话框重新读取 Catalog 中保存的列表。关闭并再次打开对话框时也会重新读取，因此界面反映的是持久化会话状态，而非临时开关状态。

<a id="mechanisms"></a>

## 内部机制

最新内容和搜索各最多返回 20 条，每条摘要最多 2,000 个 Unicode code point；打开准确版本时最多返回 20,000 个 code point。这些上限控制页面大小，同时保留足够的预览和较长的阅读视图。来源完整度与文字缩短标记会分别说明原始来源是否不完整，以及展示文字是否被截断。

准确引用包含全部三个身份。打开旧版本时不会自动替换为最新版本。如果 Current 后来删除了该版本，已有引用仍会显示并可移除；打开内容时会说明该版本不可用。列出和移除引用只访问 Dwell Catalog，因此 Current 离线时仍可执行。离线时不能新增引用，因为 Host 必须先确认准确版本仍存在。

浏览器按对话框、所选会话和请求先后顺序隔离读取结果。对话框关闭、会话切换或更晚的请求开始后，迟到的搜索或阅读结果都会被忽略。引用修改在同一对话框内串行执行，完成后再读取保存列表，避免旧响应覆盖新的持久化状态。

<a id="technology"></a>

## 技术选择

围绕 Current 公开的本地 API 的小型适配层将内容语义和存储留在 Current 中，同时为 Dwell 提供稳定且有界的视图。绑定将引用固定到指定的本地内容库。Current 保存文章正文，Dwell 保存关联到会话的引用。

这种边界让没有 Current 的 Dwell 仍可运行，并使内容库中断时的引用管理继续可用。读取正文仍依赖配置的 Current 存储库；已保存身份仍是引用，不能代替离线正文。用户选择哪些引用关联到会话；这些关联与 Pi 输入相互独立。

<a id="verification"></a>

## 关键场景与结果

未配置 Current 时，Host 应继续支持普通会话，内容库浏览则应说明当前没有可用内容库。已配置的内容库无法打开时，Host 仍应可用。最新内容和搜索结果都不得超过 20 条；阅读引用应返回指定版本，而非任意最新版本。

Current 删除某个版本后，会话引用仍应显示且可移除，但正文不可读。Current 离线时列出和移除仍应成功，新增引用必须先成功读取准确版本。添加引用不得改变 Pi 上下文、轮次请求内容或对话历史。尝试让同一绑定指向另一个根目录应被拒绝。
